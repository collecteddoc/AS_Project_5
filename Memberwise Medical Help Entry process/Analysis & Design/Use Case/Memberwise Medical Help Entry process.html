Remission Solution: 

Remission automation is not possible via PMIS, but it can be solved using below method through AMMS HRM module.
Below Transaction will be executed while performing remission transaction from HRM Transaction for that particular Penalty Account. Here only challenge is if anyone perform Reverse Remission e.g. Edit/Delete.

Penalty Amount = 1200
Penalty Outstanding Amount = (Penalty Amount - Total Penalty Deducted)

(Remission before no deduction or after penalty partially deducted, but has enough outstanding)
Case 1: (Remission Amount < Penalty Outstanding Amount)                       -- Remission Amount = 400,  Penalty Outstanding Amount = 1000
            Then
                    Transaction 1: Update New Penalty Amount
                                     => "Penalty New Amount" = "Penalty Old Amount" - "Remission Amount"= (1200 -400) tk = 800 tk (No accounting voucher)
            End

(Remission after penalty partially deducted and has not enough outstanding)
Case 2: If ("Remission Amount" > "Penalty Outstanding Amount" and "Penalty Outstanding Amount" > 0)  -- Remission Amount = 600,  Penalty Outstanding Amount = 400
            Then
                  Transaction 1: Update New Penalty Amount (Nullifying outstanding)
                                    => "Penalty New Amount" = "Penalty Old Amount" - "Penalty Outstanding Amount" = (1200 - 400) tk = 800 tk (No accounting voucher)
                  Transaction 2: Remission Amount Returned by Cash
                                    =>Remission-Cash Amount = ("Remission Amount" - "Penalty Outstanding Amount") = (600 - 400) tk = 200 tk (Auto calculated by the system) (Accounting voucher)
            End

(Remission after penalty full paid)
Case 3 : If ("Remission Amount" > "Penalty Outstanding Amount" and "Penalty Outstanding Amount" = 0)   -- Remission Amount = 1200,  Penalty Outstanding Amount = 0
             Then
                     Transaction 2: Remission Amount Returned by Cash
                                       =>Remission-Cash Amount = "Remission Amount" = 1200 tk = 1200 tk (Auto calculated by the system) (Accounting voucher)
              End

Remission-Cash GL Head                                           DR     400
Cash                                                                             CR     400
